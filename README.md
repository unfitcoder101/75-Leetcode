# 75-Leetcode

Personal DSA practice repository — C++ solutions to LeetCode problems, organized by pattern rather than by problem number, so each technique can be revisited and reviewed on its own before interviews. Later shifting the whole repo into my own project to look at its working and good user friendly management and tracking of the problems 

## Structure

```
75-Leetcode/
├── Binary_Search/     # binary search variants (search space reduction, ceil/floor, rotated arrays, etc.)
├── Hashmap/           # hashmap/hashset-based problems
├── Two Pointers/      # two-pointer and in-place array techniques
├── graphs/            # graph traversal — BFS/DFS, flood fill, multi-source problems
├── dp/                # dynamic programming
└── README.md
```

## Language

C++                  

## Why pattern-based               

Grouping by technique instead of by difficulty or source list makes it faster to drill a specific weak area (e.g. "all binary search problems") instead of re-scanning solved problems scattered across unrelated topics.                 

## Status             

Actively updated as new problems are solved and existing solutions are refined.
